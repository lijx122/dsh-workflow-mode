2. 主题机制（必须照抄）

  • 浅色 = CSS 变量写在 body {} 默认层；深色整体覆盖在 body[data-ds-dark-theme] {}。与 DSH 官方主题插件同一开关属性。
  • 工具栏 ☀️/🌙 按钮 toggle 该属性并 localStorage 记忆（键 mockup-theme）；真实实现应改挂 DSH 全局主题设置，跟随宿主自动切换。
  • 禁止硬编码黑白灰——所有叠加色（点阵、连线、悬停、阴影、端口、代码块）都必须走上方语义变量。

3. 节点类型扩展调色板 (工作流专属，双主题共用)

  • start / end: #61666b (中性端点)
  • llm: 品牌蓝 (随主题取 business-primary 官方值)
  • subagent: #06b6d4 (青色子 Agent 协作)
  • if_else: #f59e0b (琥珀条件分支)
  • template: #ec4899 (粉色文本渲染)
  • code: #8b5cf6 (紫色脚本计算)

4. 布局与圆角规范

  • 三栏规则：中部画布默认 ~62% 弹性伸缩；右侧属性面板 420px (min 380px，支持拖拽记忆)。
  • 状态表现：running (品牌蓝描边+脉冲)；completed (绿描边)；failed (红描边)；pending (opacity:0.68 无描边)。
  • 阶梯圆角：控件/按钮 8px；节点卡片 10px；大面板 14px。
